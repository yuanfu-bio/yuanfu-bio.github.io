# Yuan Fu · 符源

Personal research homepage: https://yuanfu-bio.github.io/

Static HTML, CSS and JavaScript. GitHub Pages serves the `main` branch at the repository root; `.nojekyll` preserves static assets directly.

- `index.html`: page structure and profile links
- `content.js`: research, biological context, publications, education and awards
- `app.js`: content rendering, research details and media viewer
- `styles.css`: desktop, mobile and print styling
- `assets/`: referenced figures, videos, documents and the current one-page CV
- `resume.html` / `resume.pdf`: one-page resume
- `resume-detailed.html` / `resume-detailed.pdf`: detailed resume

Research figures and materials belong to their respective authors. Manuscripts in preparation are identified on the homepage.
